# Upravljanje Iznajmljivanjem Stanova
Desktop klijent-server aplikacija za evidenciju i upravljanje iznajmljivanjem stanova, rađena kao seminarski rad.



## Cilj Projekta
Automatizacija procesa iznajmljivanja stanova kroz troslojnu arhitekturu.



## Tehnologije
- Jezik: Java (SE)
- GUI: Java Swing
- Baza podataka: MySQL / MariaDB (JDBC connector)



## Struktura Projekta
1. StanoviZajednicki – Model baze, klase i DTO objekti za prenos podataka.
2. StanoviServer – Poslovna logika i direktna komunikacija sa bazom.
3. StanoviKlijent – Korisnički interfejs za rad zaposlenih (prijava, unos, pretraga).
